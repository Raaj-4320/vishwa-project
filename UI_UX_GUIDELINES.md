# UI/UX GUIDELINES

## Sitemap
- Public: landing, login, register, forgot password, discover, store, product.
- Customer: dashboard, profile, addresses, cart, checkout, orders, order details, prescriptions, notifications, support, wishlist.
- Seller: dashboard, store profile, service areas, medicines, add/edit medicine, batches, low stock, expiry alerts, purchases, orders, prescription approvals, staff, analytics, settings.
- Delivery: dashboard, assigned, delivery detail.
- Admin: dashboard, users, sellers, verification, medicine catalog, categories, orders, reports, support, audit logs, settings.

## Design System
- Tokenized palette, spacing scale (4px base), radius, shadows.
- Reusable primitives: Button, Input, Select, Badge, Card, Table, Modal, Drawer.
- Responsive breakpoints: 640, 768, 1024, 1280.
- Status color semantics for order/prescription/verification.

## UX Standards
- Skeletons and empty states for every table/list.
- Form-level and field-level validation feedback.
- Route-level access denial fallback with clear messaging.
